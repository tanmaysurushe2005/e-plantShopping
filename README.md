Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux Toolkit. It lets users browse a curated collection of houseplants, add them to a shopping cart, and manage their purchases in a simple, user-friendly way.

Features
Landing page with a background image, the company name, a short introduction, and a "Get Started" button.
About Us section describing Paradise Nursery and its mission.
Product listing page showing houseplants grouped into categories (Air Purifying, Aromatic, Low Maintenance). Each plant has a thumbnail, name, description, and price.
Add to Cart buttons that add a plant to the cart, disable themselves once the plant is added, and update the cart icon count.
Navbar with links to Home, Plants, and Cart, plus a cart icon that shows the total number of items.
Shopping cart page that shows each plant's thumbnail, name, unit price, and subtotal, along with the total cart amount.
Quantity controls (+ / −) to increase or decrease the quantity of each plant, and a Delete button to remove it.
Checkout button (shows "Coming Soon") and a Continue Shopping button that returns to the product listing.
Tech Stack
React (Vite)
Redux Toolkit and React Redux for state management
CSS for styling
Getting Started

npm run dev
